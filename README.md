# Мими Money — кавайный финансовый дневник

Мобильный PWA-проект для учёта расходов и доходов в донгах и рублях.

## Что уже есть
- Главный экран с общим балансом, доходами и расходами.
- Мантра-манифестация, которая меняется по нажатию.
- Доходы и расходы с датой, категорией и заметкой.
- Категории: продукты, дом, транспорт, Grab, кафе и фо, здоровье, спорт, дети, развлечения, покупки, связь, путешествия и другое.
- Корзинка для покупок: товар, цена за единицу, количество, единица измерения, магазин; автоматический расчёт суммы и запись всего чека одним расходом.
- Конвертор RUB ↔ VND с редактируемым курсом.
- Стартовый остаток денег, история, фильтр доходов/расходов и экспорт JSON.
- Локальное сохранение без аккаунта и электронной почты.
- PWA-манифест, иконка и service worker для установки и базовой офлайн-работы.

## Запуск локально
Нужен Node.js 18+.

```bash
npm install
npm run dev
```

Vite покажет локальный адрес для просмотра.

## Сборка
```bash
npm run build
```
Результат будет в `dist/`.

## Бесплатная публикация на GitHub Pages
1. Создай новый GitHub-репозиторий и загрузи содержимое проекта.
2. В настройках репозитория включи Pages через GitHub Actions либо настрой публикацию содержимого `dist/`.
3. Для сборки через Actions укажи base path репозитория в `vite.config.js` (если репозиторий не `username.github.io`).
4. Открой опубликованный адрес по HTTPS на телефоне и выбери «Добавить на главный экран».

Для простого репозитория с названием, например, `mimi-money`, в `vite.config.js` нужен `base: '/mimi-money/'`. Для пользовательского домена или репозитория `username.github.io` используй `base: '/'`.

## Важно про TWA
Этот проект — устанавливаемый PWA, подготовленный как веб-основа для Android Trusted Web Activity (TWA). Сам APK/AAB нельзя завершить без опубликованного HTTPS-домена, Android application ID и ключа подписи. После публикации PWA можно упаковать через Bubblewrap и добавить `/.well-known/assetlinks.json` с отпечатком сертификата. До этих шагов приложение работает как сайт/PWA и устанавливается на экран телефона.

## Где хранятся данные
Все записи сохраняются локально в браузере на этом устройстве. Никакие данные автоматически не отправляются на сервер. Чтобы перенести их на другое устройство, нажми «Экспортировать данные JSON». Сейчас синхронизации между устройствами нет.

## Обменный курс
Начальное значение курса — 1 ₽ = 300 ₫, только как редактируемый пример. Обновляй его вручную под фактический курс своего обмена.
